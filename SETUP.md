# Quizdesk — run in VS Code
1. Install Node.js 20+ (https://nodejs.org) or Bun (https://bun.sh).
2. Open this folder in VS Code, then open the terminal (Ctrl+`).
3. Run `npm install` (or `bun install`).
4. Run `npm run dev` and open the URL shown (usually http://localhost:8080).
Run tests: `npx vitest run`.
